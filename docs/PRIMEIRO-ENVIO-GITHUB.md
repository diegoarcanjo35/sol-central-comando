# Primeiro envio ao GitHub

Repositório de destino:

`https://github.com/diegoarcanjo35/sol-central-comando`

## Pelo site do GitHub

1. Baixe e descompacte `sol-central-comando-v0.1.0.zip` no computador.
2. Abra o repositório no GitHub.
3. Na tela do repositório vazio, clique em **uploading an existing file**.
4. Abra a pasta descompactada e arraste **todo o conteúdo interno** para o GitHub.
5. Não envie o arquivo ZIP nem uma pasta externa envolvendo o projeto.
6. Use a mensagem de commit `release: v0.1.0`.
7. Confirme em **Commit changes**.

## Criar a marca da versão

Depois que os arquivos aparecerem no repositório:

1. abra **Releases**;
2. clique em **Draft a new release**;
3. em **Choose a tag**, digite `v0.1.0` e crie a tag;
4. use o título `SOL — v0.1.0`;
5. copie o resumo da versão em `CHANGELOG.md`;
6. publique a release.

## Próximos commits

Use mensagens curtas e específicas, por exemplo:

- `feat: salvar atividades no banco`
- `fix: impedir travamento do botão de voz`
- `docs: atualizar instalação`
- `release: v0.2.0`

Nunca envie arquivos `.env` nem chaves de API para o GitHub.
