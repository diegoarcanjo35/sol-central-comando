# Atualização SOL v0.1.1

Este pacote contém somente os arquivos alterados entre `v0.1.0` e `v0.1.1`.

## Enviar ao GitHub

1. Descompacte `atualizacao-sol-v0.1.1.zip`.
2. Abra o repositório `diegoarcanjo35/sol-central-comando`.
3. Clique em **Add file → Upload files**.
4. Arraste todos os arquivos e a pasta `app` que estão dentro da pasta descompactada.
5. Confirme que o GitHub mostra os arquivos como modificados, não como duplicados.
6. Use o commit `fix: prevent mobile voice button freeze`.
7. Clique em **Commit changes**.

## Criar a versão

Depois do commit:

1. abra **Releases → Draft a new release**;
2. crie a tag `v0.1.1` apontando para `main`;
3. use o título `SOL — v0.1.1`;
4. marque como **pre-release**;
5. publique.

Não remova nem altere `.gitignore`, `.npmrc` ou `.openai/hosting.json`.
